# 授权提示翻译器 / Approval explainer

当 Agent 需要更高权限或执行潜在危险操作时，DeepSeek Harness 会弹出授权确认框。原生授权框往往只显示一行技术性理由（例如 “Allow this operation with danger-full-access permissions: …”）。本插件在授权框弹出前拦截该请求，将命令解析为普通人能读懂的说明，并在**右侧栏**新增“授权记录”列表展示历史。

## 功能

- **拦截授权请求**：在 `approval/request` 瀑布事件的最前端，早于界面的远程转发监听器。
- **翻译成易懂文字**：把要执行的 shell 命令（bash / PowerShell）或文件操作解析为一句中文（及英文）说明，例如 `rm -rf node_modules` → “永久删除 node_modules，删除后无法恢复”。
- **标注危险动作**：识别破坏性 / 高风险命令（格式化、删除根目录、管道直接执行下载内容、删除数据库、`dd` 覆写磁盘、关机重启、递归改权限、sudo 等），并在授权框标题中标注 ⚠️ 危险操作 / ✎ 会修改数据 / ✓ 常规操作。
- **重新整理授权框**：合并为易读的多行排版 —— 危险等级、操作说明、Agent 理由、所需权限、原始命令，均按当前界面语言（中文优先，其他语言回退英文）展示。
- **右侧栏授权记录**：右侧栏新增“授权记录”面板，实时列出每次授权提示的解释、对应命令、危险等级与结果（已允许 / 已拒绝 / 已取消 / 未处理）。该列表来自宿主端会话投影，随会话日志自动更新。
- **零侵入**：本插件只改写展示文本与派生展示数据，从不代替用户放行或拒绝，也不改动审计事件；识别失败会原样放行，绝不阻断审批流程。

## 使用

安装并启用后无需配置。出现授权提示时，弹窗展示翻译后的说明与危险等级；右侧栏可打开“授权记录”面板查看历史列表（可按需从指南页打开）。原始命令始终保留以便核对。

## 原理

- **弹窗翻译**：Host 侧在 `approval/request` 瀑布用 `prepend + global` 注册监听，改写 `displayReason`（仅展示，审计 `approval/asked` 的 `reason` 保持不变）。
- **历史列表**：Host 侧以会话投影（`approvalExplainers`，含 `wire` 视图）折叠 `approval/asked` / `approval/decided` / `tool/call` 事件，生成每条记录的解释与命令；Client 侧通过会话标准 `useProjection('approvalExplainers')` 读取并渲染到右侧栏。
- 采用确定性规则表（无网络、无大模型调用）。
